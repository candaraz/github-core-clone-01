A single-process GitHub-compatible git forge: git smart HTTP (protocol v2 and v0), GitHub REST API v3, GraphQL, and an MCP server, implemented from the wire protocols up in dependency-free TypeScript with no git binary. Packs are cached per request, objects are deflated once, and every surface shares one in-memory store, so clones, pushes, reads, and writes all stay fast.

## Run it

```sh
node main.ts
```
